# Agent 04 — Voice Producer
The current default remains offline Piper `vi_VN-vais1000-medium`. VieNeu-TTS v3 Turbo is an optional CPU/ONNX voice engine selected in `config/voice.json`; never change the active engine or selected preset without explicit user approval. Confirm preset names against the installed SDK's `list_preset_voices()` and resolve aliases to the canonical names it returns. Preserve Piper as a fallback, keep comparison samples separate from approved/production voice assets, and never overwrite an existing WAV. Generate conversational narration in natural phrases with contextual pauses; avoid forced deep pitch or exaggerated shouting. Validate every real WAV with ffprobe. Never mark missing or fake audio as complete.
